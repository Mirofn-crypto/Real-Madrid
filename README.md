# Real Madrid Club

Site vitrine statique en français, prêt pour GitHub Pages. Le projet présente un club sportif indépendant et ses disciplines ; il n’est pas affilié au Real Madrid C.F.

## Publication

Dans GitHub, ouvrez Settings → Pages, choisissez Deploy from a branch, sélectionnez main et le dossier root, puis enregistrez. Après le déploiement, le site est publié à l’adresse https://mirofn-crypto.github.io/Real-Madrid/.

## Référencement

Le site inclut des titres et descriptions par page, des URL canoniques, des métadonnées Open Graph, un balisage JSON-LD pour le site et une FAQ éditoriale, ainsi que robots.txt et sitemap.xml. Les deux derniers fichiers utilisent l’URL GitHub Pages du dépôt.

## Fichiers

- index.html : accueil
- club.html : présentation du club
- realmadrid.html : activités et questions fréquentes
- contact.html : informations de contact
- style.css : styles communs
- robots.txt et sitemap.xml : directives et URLs d’exploration

Le formulaire et les coordonnées de contact n’étant pas configurés, la page Contact l’indique clairement. Le site ne contient ni clé API ni configuration locale.
